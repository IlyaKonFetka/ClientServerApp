# ClientServerApp

Тестовое задание в BH Team. Два Android-приложения и общий модуль `common_code`.

`server` запускается на телефоне с root. Он по таймеру сканирует `/data/data/com.android.chrome`, хранит сканы в SQLite и подсвечивает, какие файлы появились или пропали с прошлого раза. Ещё умеет упаковать папку в архив и залить обратно: останавливает Chrome, подменяет данные, выставляет права и запускает его снова.

`client` подключается к серверу по WebSocket (Ktor) и управляет всем этим удалённо.
